# AI / Developer Operating Contract

This repository follows Cody Development Playbook v1.0 from the canonical local playbook directory.

## Project Rules

- Keep the public site static, dependency-free, and limited to reviewed legal information.
- Do not add analytics, advertising, tracking, cookies, forms, or remote executable resources.
- Run `npm test` before opening or updating a pull request.
- Use short-lived branches and pull requests; do not commit material changes directly to `main`.
- Require independent review for AI-assisted changes.
